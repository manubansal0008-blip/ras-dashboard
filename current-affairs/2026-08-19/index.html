RAS Current Affairs — 19 August 2026

Daily current-affairs MCQs for the RPSC RAS exam, dated 19 August 2026 — with answers and explanations.

Rajasthan — Tourism

1. Consider the following statements:
(a) Amer Fort was built by Sawai Jai Singh II.
(b) The 2nd BRICS Tourism Working Group meeting was held in Jaipur.
(c) Delegates visited Hawa Mahal, City Palace and Amer.
(d) Hawa Mahal was built by Sawai Pratap Singh.
Which of the above statements is/are correct?

  1. Only b, c and d
  2. a, b, c and d
  3. Only a, b and c
  4. Only a and b

Answer: A. Only b, c and d — Statement a is wrong: Amer Fort was built mainly by Raja Man Singh I.

International — Humanitarian

2. Consider the following statements:
(a) World Humanitarian Day is observed on 19 August.
(b) World Humanitarian Day was declared by the UN Security Council.
(c) World Humanitarian Day marks the 2003 bombing of the UN office in Baghdad.
(d) Sergio Vieira de Mello was killed in the Baghdad bombing.
Which of the above statements is/are correct?

  1. a, b, c and d
  2. Only b, c and d
  3. Only a, c and d
  4. Only a and c

Answer: C. Only a, c and d — Statement b is wrong: the UN General Assembly declared it in 2008.

Jaipur — Monuments

3. Match List-I (Monument) with List-II (Builder) and select the correct answer using the code given below:
List-I
(A) Hawa Mahal
(B) Jantar Mantar
(C) Amer Fort
(D) Albert Hall Museum
List-II
(1) Sawai Ram Singh II's reign
(2) Sawai Jai Singh II
(3) Raja Man Singh I
(4) Sawai Pratap Singh
Code:

  1. A-4, B-3, C-2, D-1
  2. A-4, B-2, C-3, D-1
  3. A-2, B-4, C-3, D-1
  4. A-3, B-2, C-1, D-4

Answer: B. A-4, B-2, C-3, D-1 — BRICS tourism delegates visited Jaipur's monuments.

Defence — Armenia

4. Read the following and choose the correct answer:
Assertion (A): India and Armenia have expanded defence ties.
Reason (R): Armenia has bought Indian systems such as Pinaka rocket launchers.

  1. Both A and R are true, and R is the correct explanation of A
  2. Both A and R are true, but R is not the correct explanation of A
  3. A is true, but R is false
  4. A is false, but R is true

Answer: A. Both A and R are true, and R is the correct explanation of A — Both are true and R explains A.

Countries — Capitals

  2. Georgia — Tbilisi
  3. Azerbaijan — Baku
