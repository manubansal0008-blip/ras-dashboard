RAS Current Affairs — 20 July 2026

Daily current-affairs MCQs for the RPSC RAS exam, dated 20 July 2026 — with answers and explanations.

Rajasthan — Local Body Elections

1. Consider the following statements:
(a) The State told the High Court that panchayat and municipal elections will be completed by 15 November.
(b) Elections to municipalities are conducted by the Election Commission of India.
(c) The OBC Commission's report is due by 5 August.
(d) Elections to panchayats are conducted by the State Election Commission.
Which of the above statements is/are correct?

  1. a, b, c and d
  2. Only a and c
  3. Only b, c and d
  4. Only a, c and d

Answer: D. Only a, c and d — Statement b is wrong: municipal elections are also conducted by the State Election Commission (Article 243ZA).

Space — Private Launch

2. Consider the following statements:
(a) Vikram-1 was developed by Hyderabad-based Skyroot Aerospace.
(b) Vikram-1 was launched under Mission 'Aagaman'.
(c) Vikram-1's liquid engine is named after C.V. Raman.
(d) Vikram-S, launched in 2022, reached a stable orbit.
Which of the above statements is/are correct?

  1. a, b, c and d
  2. Only b, c and d
  3. Only a, b and c
  4. Only a and b

Answer: C. Only a, b and c — Statement d is wrong: Vikram-S was a suborbital flight and did not reach orbit.

Economy — Indices

3. Consider the following statements:
(a) NITI Aayog released the first Investment Friendliness Index in 2026.
(b) Gujarat ranked first in the Investment Friendliness Index 2026.
(c) The Investment Friendliness Index uses 84 indicators across eight pillars.
Which of the above statements is/are correct?

  1. Only a and b
  2. Only a and c
  3. Only b and c
  4. a, b and c

Answer: D. a, b and c — All three are correct. Maharashtra and Tamil Nadu followed Gujarat.

Literature — Jnanpith

4. Match List-I (Writer) with List-II (Language / note) and select the correct answer using the code given below:
List-I
(A) R. Vairamuthu
(B) Akilan
(C) G. Sankara Kurup
(D) Gulzar
List-II
(1) Malayalam — first Jnanpith winner
(2) Tamil — 60th award
(3) Urdu
(4) Tamil — first Tamil winner
Code:

  1. A-3, B-1, C-4, D-2
  2. A-4, B-2, C-1, D-3
  3. A-1, B-2, C-4, D-3
  4. A-2, B-4, C-1, D-3

Answer: D. A-2, B-4, C-1, D-3 — Vairamuthu is the third Tamil writer to win the Jnanpith Award. G. Sankara Kurup received the first award in 1965.

Wildlife — Reintroductions

5. Which one of the following pairs (species — fact) is NOT correctly matched?

  1. Indian Grey Hornbill — Gir
  2. Cheetah — Kuno
  3. Indian Grey Hornbill — Critically Endangered
  4. Spotted deer — Schedule II

Answer: C. Indian Grey Hornbill — Critically Endangered — The Indian Grey Hornbill is listed as Least Concern by the IUCN.
