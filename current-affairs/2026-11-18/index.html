RAS Current Affairs — 18 November 2026

Daily current-affairs MCQs for the RPSC RAS exam, dated 18 November 2026 — with answers and explanations.

International — Quad

1. Consider the following statements:
(a) The Quad was first proposed by Australian PM Kevin Rudd in 2007.
(b) The Manila meeting was the 7th Quad Leaders' Summit.
(c) India will host the first Quad Business Leaders' Forum in Mumbai in 2027.
(d) The first Quad-level maritime military exercise will be held in 2027.
Which of the above statements is/are correct?

  1. Only a and b
  2. Only b, c and d
  3. a, b, c and d
  4. Only a, b and c

Answer: B. Only b, c and d — Statement a is wrong: the Quad was proposed by Japanese PM Shinzo Abe in 2007.

Health — Malaria

2. Consider the following statements:
(a) Malaria cases and deaths in India fell by nearly 80% between 2015 and 2025.
(b) India exited the WHO's High Burden to High Impact group in 2024.
(c) High-burden districts rose from 33 to 155 over the decade.
(d) India aims to eliminate malaria by 2030.
Which of the above statements is/are correct?

  1. Only a and b
  2. a, b, c and d
  3. Only a, b and d
  4. Only b, c and d

Answer: C. Only a, b and d — Statement c is wrong: high-burden districts fell from 155 to 33.

Current Affairs — Facts

List-II
(1) State bird of Ladakh

Rajasthan — Law

4. Consider the following statements:
(a) Rajasthan was the first State to pass an Advocates Protection Bill.
(b) Under the Bill, assault on an advocate is punishable with up to 7 years' imprisonment.
(c) Complaints are to be investigated by an officer not below the rank of Deputy Superintendent of Police.
Which of the above statements is/are correct?

  1. Only a and b
  2. a, b and c
  3. Only b and c
  4. Only a and c

Answer: D. Only a and c — Statement b is wrong: assault carries up to 2 years; up to 7 years is for grievous hurt.

Rajasthan — Urban Transport

5. Consider the following statements:
(a) Rajasthan has approval for 1,150 e-buses under PM e-Bus Sewa.
(b) Jaipur has the largest share of these buses.
(c) Sikar was part of the original list of eight cities.
(d) PM e-Bus Sewa uses a public-private partnership model.
Which of the above statements is/are correct?

  1. a, b, c and d
  2. Only b, c and d
  3. Only a, b and d
  4. Only a and b

Answer: C. Only a, b and d — Statement c is wrong: Sikar was added later, making nine cities.

Rajasthan — e-Bus allocation

6. Which one of the following pairs (city — e-buses) is NOT correctly matched?

  1. Udaipur — 50
  2. Jaipur — 550
  3. Bikaner — 100
  4. Jodhpur — 125

Answer: C. Bikaner — 100 — Bikaner is allotted 75 e-buses; Ajmer and Kota get 100 each.
