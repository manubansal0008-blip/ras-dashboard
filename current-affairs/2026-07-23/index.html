RAS Current Affairs — 23 July 2026

Daily current-affairs MCQs for the RPSC RAS exam, dated 23 July 2026 — with answers and explanations.

Rajasthan — Maternal Health

1. Consider the following statements:
(a) 'Prasav Sakhi' will first start in private nursing homes.
(b) Rajasthan is launching the 'Prasav Sakhi' scheme for high-risk pregnant women.
(c) Under 'Prasav Sakhi', trained nurses and ANMs assist women from admission to aftercare.
(d) 'Prasav Sakhi' will be linked with the 104 Janani Express service.
Which of the above statements is/are correct?

  1. Only a and b
  2. Only a, b and c
  3. a, b, c and d
  4. Only b, c and d

Answer: D. Only b, c and d — Statement a is wrong: it starts in medical college hospitals, district hospitals and high-load referral units.

Polity — Internet Shutdowns

2. Consider the following statements:
(a) Only the Union Home Minister can order an internet suspension.
(b) Internet shutdowns are now governed by rules framed under the Telecommunications Act, 2023.
(c) A suspension order cannot exceed 15 days.
(d) Anuradha Bhasin v. Union of India was decided in 2020.
Which of the above statements is/are correct?

  1. Only a and b
  2. Only a, b and c
  3. Only b, c and d
  4. a, b, c and d

Answer: C. Only b, c and d — Statement a is wrong: orders are issued by the Union or State Home Secretary.

Economy — Currency

3. Read the following and choose the correct answer:
Assertion (A): Polymer currency notes last longer than paper notes.
Reason (R): Polymer notes cost less to manufacture than paper notes.

  1. Both A and R are true, and R is the correct explanation of A
  2. Both A and R are true, but R is not the correct explanation of A
  3. A is true, but R is false
  4. A is false, but R is true

Answer: C. A is true, but R is false — R is false: polymer notes cost about 30–60% more to make. A is true.

Birds — Status

4. Which one of the following pairs (bird — fact) is NOT correctly matched?

  1. White-bellied Heron — Critically Endangered
  2. Great Indian Bustard — Critically Endangered
  3. Indian Grey Hornbill — Least Concern
  4. White-bellied Heron — Mainly found in Rajasthan

Answer: D. White-bellied Heron — Mainly found in Rajasthan — In India, the White-bellied Heron is found mainly in Arunachal Pradesh, especially the Lahm river basin.
