RAS Current Affairs — 8 November 2026

Daily current-affairs MCQs for the RPSC RAS exam, dated 8 November 2026 — with answers and explanations.

Rajasthan — History Sources

1. Consider the following statements:
(a) Prithviraj Raso was composed by Chand Bardai.
(b) Muhnot Nainsi is known as the 'Abul Fazal of Rajputana'.
(c) 'Annals and Antiquities of Rajasthan' was written by James Tod.
(d) Kanhadde Prabandh was composed by Chand Bardai.
Which of the above statements is/are correct?

  1. Only a and b
  2. Only a, b and c
  3. Only b, c and d
  4. a, b, c and d

Answer: B. Only a, b and c — Statement d is wrong: Kanhadde Prabandh was composed by Padmanabh. It describes Kanhaddeo of Jalore's resistance to Alauddin Khilji.

Rajasthan — Water Resources

2. With reference to the Yamuna Water Project for Shekhawati, consider the following statements:
(a) Water will be carried by underground pipeline from Hathnikund Barrage to the Hansiyawas reservoir in Churu district.
(b) Under the 1994 Upper Yamuna agreement, Rajasthan was allotted a share of Yamuna water at Tajewala during the monsoon.
(c) The Yamuna Water Project is meant to benefit the Sikar, Churu and Jhunjhunu districts.
(d) Hathnikund Barrage is located in Uttar Pradesh.
Which of the above statements is/are correct?

  1. Only a and b
  2. Only a, b and c
  3. Only b, c and d
  4. a, b, c and d

Answer: B. Only a, b and c — Statement d is wrong: Hathnikund Barrage is in Yamunanagar, Haryana. The pipeline is about 295.5 km long, costs about ₹34,000 crore and follows the Rajasthan–Haryana MoA of 29 June 2026.

Rajasthan — Fairs

3. Match List-I (Fair) with List-II (District) and select the correct answer using the code given below:
List-I
(A) Pushkar fair
(B) Kolayat (Kapil Muni) fair
(C) Chandrabhaga fair
(D) Baneshwar fair
List-II
(1) Dungarpur
(2) Jhalawar
(3) Ajmer
(4) Bikaner
Code:

  1. A-4, B-3, C-1, D-2
  2. A-3, B-1, C-4, D-2
  3. A-3, B-4, C-1, D-2
  4. A-3, B-4, C-2, D-1

Answer: D. A-3, B-4, C-2, D-1 — Pushkar, Kolayat and Chandrabhaga (Jhalrapatan) fairs are held around Kartik Purnima. Baneshwar, the 'Kumbh of the tribals', is held on Magh Purnima.

Art & Culture — Heritage

4. With reference to the Indian manuscripts added to UNESCO's Asia-Pacific Memory of the World Register, consider the following statements:
(a) The Rajatarangini was written by Kalhana in the 12th century.
(b) The Arthashastra is attributed to Kautilya.
(c) UNESCO's Memory of the World Programme was launched in 1992.
(d) The Rajatarangini is a chronicle of the kings of Gujarat.
Which of the above statements is/are correct?

  1. Only a and b
  2. Only a, b and c
  3. a, b, c and d
  4. Only b, c and d

Answer: B. Only a, b and c — Statement d is wrong: the Rajatarangini is a chronicle of Kashmir. Manuscripts of the Mahabharata, Rajatarangini and Arthashastra were added at the 11th MOWCAP session in Jakarta.

Important Days — Science

5. Read the following and choose the correct answer:
Assertion (A): World Radiography Day is observed on 8 November.
Reason (R): Wilhelm Conrad Röntgen discovered X-rays on 8 November 1895.

  1. Both A and R are true, and R is the correct explanation of A
  2. Both A and R are true, but R is not the correct explanation of A
  3. A is true, but R is false
  4. A is false, but R is true

Answer: A. Both A and R are true, and R is the correct explanation of A — Both are true and R explains A. Röntgen received the first Nobel Prize in Physics in 1901.
