RAS Current Affairs — 14 October 2026

Daily current-affairs MCQs for the RPSC RAS exam, dated 14 October 2026 — with answers and explanations.

Rajasthan — Environment

1. Consider the following statements:
(a) Amrita Devi Bishnoi led the Khejarli sacrifice in 1730.
(b) Khejarli village is in Jodhpur district.
(c) The Khejarli movement was launched to save peepal trees.
(d) 363 people sacrificed their lives in the Khejarli movement.
Which of the above statements is/are correct?

  1. Only a, b and d
  2. Only b, c and d
  3. a, b, c and d
  4. Only a and b

Answer: A. Only a, b and d — Statement c is wrong: it was to save Khejri trees. The State-level Amrita Haat at Shilpgram is named after Amrita Devi.

Environment — Movements

2. Match List-I (Movement) with List-II (State) and select the correct answer using the code given below:
List-I
(A) Chipko
(B) Appiko
(C) Khejarli
(D) Silent Valley
List-II
(1) Kerala
(2) Rajasthan
(3) Uttarakhand
(4) Karnataka
Code:

  1. A-3, B-4, C-2, D-1
  2. A-3, B-4, C-1, D-2
  3. A-3, B-1, C-4, D-2
  4. A-4, B-3, C-2, D-1

Answer: A. A-3, B-4, C-2, D-1 — Khejarli (1730) is regarded as the earliest recorded tree-protection movement in India.

Polity — Election Commission

3. Consider the following statements:
(a) Article 324 vests the superintendence of elections in the Election Commission.
(b) The CEC can be removed only in the manner of a Supreme Court judge.
(c) The Constitution fixes the number of Election Commissioners at two.
(d) An Election Commissioner can be removed only on the recommendation of the CEC.
Which of the above statements is/are correct?

  1. a, b, c and d
  2. Only b, c and d
  3. Only a and b
  4. Only a, b and d

Answer: D. Only a, b and d — Statement c is wrong: the number of ECs is fixed by the President; the Constitution does not fix it.

Economy — Taxation

4. Read the following and choose the correct answer:
Assertion (A): The Securities Transaction Tax (STT) was introduced in 2004.
Reason (R): STT was introduced in place of the long-term capital gains tax on listed equity.

  1. Both A and R are true, and R is the correct explanation of A
  2. Both A and R are true, but R is not the correct explanation of A
  3. A is true, but R is false
  4. A is false, but R is true

Answer: A. Both A and R are true, and R is the correct explanation of A — Both are true and R explains A. LTCG on listed equity was reintroduced in 2018.

International Organisations

5. Which one of the following pairs (Organisation — Headquarters) is NOT correctly matched?

  1. WTO — New York
  2. IAEA — Vienna
  3. IEA — Paris
  4. ICRC — Geneva

Answer: A. WTO — New York — The WTO is headquartered in Geneva.
